# MTS Coverage Map & 5G Checker 📶🚀

Интерактивное веб-приложение для проверки покрытия мобильной сети МТС (включая **5G до 300 Мбит/с**, **Супер 5G до 1.5 Гбит/с**, **4G LTE**, **3G**, **2G** и **NB-IoT**).

Основано на официальных картографических тайлах МТС (`https://tiles.qsupport.mts.ru/`) и Яндекс Картах API.

---

## 🌟 Возможности

1. **📍 Кнопка «Моё местоположение»**:
   - Автоматический запрос GPS координат через браузер (`navigator.geolocation`).
   - Центрирование карты и установка анимированного маркера на текущую геопозицию.
2. **🔍 Ручной ввод адреса или координат**:
   - Поле поиска с автодополнением адресов по городам России и Татарстана (Яндекс Саджест).
   - Поддержка ввода как текстовых адресов (*«Казань, ул. Баумана»*, *«Иннополис, Университетская»*), так и координат (*`55.7903, 49.1228`*).
3. **🗺️ Интерактивный выбор точки**:
   - Клик в любое место на карте мгновенно определяет адрес дома/улицы и проверяет доступность всех типов сетей.
4. **📶 Переключение слоев покрытия**:
   - 🔴 **5G** (до 300 Мбит/с — `g5_New`)
   - 🟣 **Супер 5G** (до 1.5 Гбит/с — `g5`)
   - 🔵 **4G LTE** (`lte_New`)
   - 🟡 **3G** (`g3_New`)
   - 🟢 **2G** (`g2_New`)
   - 🌐 **NB-IoT** (Интернет вещей)
5. **🎯 Точный детектор покрытия**:
   - Встроенный сервер проверяет наличие покрытия на уровне прозрачности пикселей тайлов и сразу выдает статус: «✓ Доступно» или «✕ Нет зоны».
6. **🌐 Работает без бэкенда (GitHub Pages Ready)**:
   - Можно запускать локально как с сервером Python, так и развернуть на GitHub Pages в виде статического сайта.

---

## 🚀 Быстрый запуск

### Вариант 1: С сервером проверки пикселей (рекомендуется)
```bash
python server.py
```
Откройте в браузере: **http://localhost:8080**

### Вариант 2: Статический запуск
Просто откройте файл `index.html` в любом современном браузере.
